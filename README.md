I work where **development meets infrastructure**—containerizing applications, building delivery pipelines, configuring reverse proxies, monitoring systems, and making deployments calmer and more repeatable.

My engineering background spans DevOps, cloud, full-stack development, IoT, and embedded systems. That mix helps me understand both the application being shipped and the platform keeping it alive.

## What I build

| Area | What I do |
|:--|:--|
| **CI/CD & Release Engineering** | Build Jenkins pipelines, automate Docker deployments, add validation and health checks, and design safer rollback flows. |
| **Containers & Linux** | Package applications with Docker, manage networks and volumes, troubleshoot Linux servers, and operate Nginx reverse proxies. |
| **Observability & Security** | Monitor infrastructure with Wazuh, Kibana, Metricbeat, and Filebeat; investigate resource spikes and authentication events. |
| **Cloud & Infrastructure** | Build on AWS and automate infrastructure with Terraform, with a focus on maintainability and least-privilege access. |
